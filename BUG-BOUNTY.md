# Setra Bug Bounty Program

| Severity | Reward |
|----------|--------|
| Critical | Up to $50,000 |
| High | Up to $15,000 |
| Medium | Up to $5,000 |
| Low | Up to $1,000 |

## Critical
- Loss of funds via unauthorized settlement
- Unauthorized sEquity minting
- Settlement without valid signatures
- PoR attestation manipulation

## High
- Freeze bypass, nonce replay, registry corruption, role escalation

## Medium
- Permanent DoS, incorrect netting, premature corporate action execution

## Rules
1. First valid report gets bounty
2. Must be reproducible on latest `main`
3. No public disclosure before fix
4. Paid in USDC on Robinhood Chain within 30 days
