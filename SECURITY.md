# Security Policy

## Reporting Vulnerabilities

**DO NOT** open public GitHub issues for security vulnerabilities.

1. Email: security@setra.finance
2. Include: description, repro steps, severity, suggested fix
3. Acknowledgment within 24 hours, detailed response within 72 hours

## Scope

In scope: setra-core, setra-registry, setra-sdk, setra-node

Out of scope: dependencies (report upstream), test/mock contracts, gas optimizations, docs
